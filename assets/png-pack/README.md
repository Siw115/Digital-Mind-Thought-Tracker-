# PNG Packs

This folder contains reusable PNG packs for the **Digital Mind / Thought Tracker** project.

## Available Pack

### `twemoji/`

Open-source emoji PNG subset (72x72), useful for playful UI accents, status visuals, and card decorations.

- Manifest: `assets/png-pack/twemoji/manifest.json`
- Attribution/license: `assets/png-pack/twemoji/ATTRIBUTION.md`
